analyze-code-similarity

Compares two files and reports a similarity score based on common tokens or lines. Standard library only, with no third party requirements to install.

First entry: the watch itself

FILE1 is the first file, FILE2 is the second file, and the score is the watcher's answer about the pair.

Second entry: posting to the tower

git clone https://github.com/ShadowGuard-AI/analyze-code-similarity
cd analyze-code-similarity

Third entry: taking a reading

python3 main.py FILE1 FILE2 [-m token|line] [-t THRESHOLD] [-v]

Read the source on GitHub

Fourth entry: the two ways of judging a column

Token mode, the default, splits on whitespace only. Its honest limit, printed with the method: punctuation stays attached to its word and case counts, so two files can read alike to a person and score apart here.

Line mode works on whole lines. Its honest limit: lines are held in sets, so duplicate lines collapse and line order is ignored, so a rearranged file scores closer than its arrangement deserves.

Fifth entry: the threshold

-t takes a value from 0.0 to 1.0 and the default is 0.7. Scores below the threshold are reported as dissimilar.

Boundary rule, given its own entry: the comparison uses greater than or equal, so a score sitting exactly on the threshold counts as similar.

The watcher's answer

The score for the pair, reported as similar or dissimilar against the threshold above.

Sightings already confirmed

Identical files score 1.0000 and are reported similar in both token and line mode. Unrelated files score 0.0000 and are reported dissimilar. A missing input file exits 1. A threshold outside 0.0 to 1.0 prints a message and exits 1. The -v switch enables verbose logging, and -h shows the help message and exits.
