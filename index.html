analyze-code-similarity

Compares two files and reports a similarity score based on common tokens or common lines.

Open the repo Usage

How the score works

Two files are laid side by side and what they share is counted, token by token or line by line. The score is compared against a threshold (default 0.7): scores below the threshold are reported as dissimilar, and the comparison uses greater than or equal, so a score exactly on the threshold counts as similar. Identical files score 1.0 and unrelated files score 0.0.

Install and usage

git clone https://github.com/ShadowGuard-AI/analyze-code-similarity
cd analyze-code-similarity

python3 main.py FILE1 FILE2 [-m token|line] [-t THRESHOLD] [-v]

Standard library only. There are no third party requirements to install: requirements.txt is empty (0 bytes), as the README states.

Parameters

FILE1, FILE2the two files to compare
-m, --modecomparison mode, token (default) or line
-t, --thresholdsimilarity threshold from 0.0 to 1.0. Default: 0.7
-v, --verboseenable verbose logging
-hshow help message and exit

Verified behavior and limits

  • Identical files score 1.0000 and are reported similar, in both token and line mode.
  • Unrelated files score 0.0000 and are reported dissimilar.
  • A missing input file exits 1.
  • A threshold outside 0.0 to 1.0 prints a message and exits 1.
  • Token mode splits on whitespace only, so punctuation stays attached and case counts.
  • Line mode uses sets, so duplicate lines collapse and line order is ignored.
